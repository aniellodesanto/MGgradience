Syntactic Gradience from an MG Parsers
===================================================


The MGParsing code is a copy of the repo made freely available by [Graf et al. (2027)](https://jlm.ipipan.waw.pl/index.php/JLM/article/view/157) to facilitate the investigation of human processing from the perspective of Minimalist grammars (MGs).

This separate repository was create to jointly collect MG scripts and LaTex source files to model gradient effects in syntactic acceptability, and to accompany the paper:

- De Santo, Aniello (to appear): [Can Categorical Grammars Really Derive Gradient Acceptability?](link to be added soon)

This repo contains Python scripts, and the complete set of trees needed to run all simulations in the paper, as well as example of how to run the code.
See the original MGproc repository  ([here](https://github.com/CompLab-StonyBrook/mgproc)) for detailed information about the implementation.
